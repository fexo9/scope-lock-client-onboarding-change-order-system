# Scope-Lock — Client Onboarding & Change-Order System

Lock scope, deposit, revisions, and change-order prices IN WRITING before work starts — so "just one small extra thing" stops being unpaid work.

## What it is

A documentation and decision system for freelancers and solo operators. Before any client work starts, you agree in writing: what the project includes, what it excludes, how many revision rounds are included, what the deposit and milestones are, and what any extra work costs. When the client asks for something outside the agreement, you price it from the Change-Order Price Sheet, log it, and get written approval before doing the extra work.

**Not legal advice.** Scope-Lock is not a lawyer, not a contract, and not a guarantee of payment. The worked example in the package is fictional.
